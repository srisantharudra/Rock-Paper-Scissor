✊ Rock Paper Scissors Game

A simple and interactive Rock Paper Scissors game built using HTML, CSS, and JavaScript. Play against the computer, test your luck, and track your score in real time!

🚀 Features

- 🎮 Interactive Rock, Paper, and Scissors buttons
- 🤖 Random computer choice
- 🏆 Automatic winner detection
- 📊 Live score tracking for the player and computer
- 🎨 Dynamic background colors for wins, losses, and draws
- ⚡ Instant results without reloading the page

🛠️ Technologies Used

- HTML5 – Structure of the game
- CSS3 – Styling and layout
- JavaScript – Game logic, DOM manipulation, and event handling
- Font Awesome – Hand icons

▶️ How to Run

1. Clone this repository:
   
   git clone https://github.com/srisantharudra/rock-paper-scissors.git

2. Open the project folder.

3. Open "index.html" in your browser.

4. Select Rock, Paper, or Scissors to play against the computer.

📖 Game Rules

Your Choice| Opponent's Choice| Result
Rock| Scissors| You win
Paper| Rock| You win
Scissors| Paper| You win
Same choices| Same choices| Draw

Otherwise, the computer wins.
